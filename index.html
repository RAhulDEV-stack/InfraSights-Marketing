Operational Reality

The SAN Visibility Challenge in Complex Data Centers

In complex DC architectures, when a Fibre Channel switch reports a port failure, storage and infrastructure teams struggle to correlate which business applications, server clusters, and host paths are degraded.

Without Infrasights (Fragmented DC Ops)

  • No Application Context: When switch logs report slot 4 port 12 offline, admins cannot tell which mission-critical app or cluster is impacted without manual cross-referencing.
  • Device-by-Device CLI Sifting: Engineers manually SSH across Cisco and Brocade switches to parse porterrshow and show interface counters during high-pressure incidents.
  • Hidden Path Failovers: Silent SAN path drops leave server clusters operating on a single fabric with zero redundancy, completely undetected until secondary paths fail.
  • Vendor Console Silos: Fragmented tools for different switch models prevent a cohesive, single-pane view of data center SAN storage topologies.

With Infrasights v2.10 (App-Wise One-View)

  • App-Wise One-View Portal: Complex DC SAN paths mapped by application. Home page pie charts represent server clusters at a glance.
  • 3-Tier Drill-Down to SAN Paths: Click an app card to see cluster pies; click a cluster to view hostnames; in each hostname, every slice represents a dedicated physical SAN path.
  • Real-Time Red Slice Alerting: If a switch reports slot X port Y down via SNMP forwarding, the exact dedicated SAN path slice turns red instantly.
  • Cisco & Brocade Compatibility: Universal support for Cisco MDS, Brocade (Broadcom), and any enterprise SAN switches with SNMP forwarding.
